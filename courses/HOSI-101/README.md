# HOSI-101 — Understanding the Human Operating System

**200 lessons · 20 modules · capstone**

This course is the common foundation for HOSI's specialized study paths. It begins with ordinary human systems before applying them to Bipolar I/II, ADHD presentations, OCD, PTSD/trauma, and brain injury.

## Lesson architecture
Each lesson is designed to contain: learning objectives; vocabulary; human-system baseline; core science; historical context; evidence map; what is known; uncertainty; condition-specific applications; combination/comorbidity panel; lived-experience perspective; practical skill; safety/scope; Cornell Notes; reflection; knowledge check; quiz; references; further reading; research update; and a “What would change our mind?” section.

# HOSI WordPress.com Launch Plan

## Verified current constraint
WordPress.com currently offers a free plan with hosted WordPress, SSL, themes/blocks, unlimited pages/posts/users and 1 GB media storage. Plugin installation requires a paid WordPress.com plan, so LearnDash/Tutor LMS Pro cannot be installed on the free plan.

## $0 MVP
1. Use the `*.wordpress.com` address.
2. Build Home, About, Colleges, HOSI-101, Research Library, Founder's Atlas, Policies, Accessibility and Contact with native blocks/pages/posts.
3. Use categories/tags and a master course index for lessons.
4. Link the GitHub repository as the canonical source.
5. Keep sensitive Atlas data outside WordPress until a privacy-safe backend exists.

## LMS upgrade gate
Upgrade only when enrollment, advanced quizzes, persistent progress, certificates, drip content or custom plugins are actually required. Document the requirement first.

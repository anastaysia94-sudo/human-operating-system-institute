# HOSI Platform Architecture 1.0

## Phase 1: near-zero-cost public campus
- WordPress.com or equivalent low-cost WordPress publishing environment.
- GitHub as canonical source control for text curriculum and policies.
- Markdown-first content for portability.
- Accessible, responsive, mobile-first templates.

## Phase 2: LMS
- Course hierarchy: college → program → course → module → lesson → assessment.
- Student progress tracking.
- Quiz/assignment infrastructure.
- Completion certificates that accurately state their status.

## Phase 3: Atlas
- Learner-controlled Atlas profile.
- Reflections, goals, timeline, learning history, projects, values, and knowledge links.
- Export/delete controls.

## Phase 4: Atlas AI
- Retrieval from approved HOSI educational sources.
- Reflection summarization with uncertainty language.
- Lesson recommendations.
- Follow-up questions.
- No diagnosis, prescribing, treatment changes, or hidden profiling.

## Quality gates
Accessibility, privacy, security, evidence verification, AI safety, medical-scope review, and learner testing must precede public production release.

## Current status
Architecture specified; production implementation has not yet been completed.

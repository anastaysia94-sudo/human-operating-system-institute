## What remains uncertain

State meaningful uncertainty. Do not hide it in the references section like an embarrassed relative.

## Condition-specific applications

Only include condition-specific implications that the evidence supports.

Do not imply:
- a symptom proves a diagnosis
- a diagnosis explains every behavior
- one mechanism determines one person
- a group average predicts an individual's destiny

## Combination / comorbidity lens

Where evidence exists, explain intersections. Explicitly state when evidence is indirect, sparse, or extrapolated.

## Lived-experience perspective

Include lived experience for questions it can appropriately answer, such as burden, meaning, usability, stigma, or day-to-day experience.

Keep lived experience distinct from population-level causal or efficacy claims.

## WordPress post settings

Before publishing:

### Categories
- `HOSI-101`
- the exact module category

### Tags
Use only relevant tags from the canonical study-path/human-system vocabulary. Avoid diagnostic keyword stuffing.

### Excerpt
Write a plain-language 1–2 sentence summary that does not overstate evidence.

### Featured image
Use an approved existing asset with alt text. Decorative imagery should not imply clinical/scientific findings.

### Slug
Recommended:
`hosi-101-###-short-title`

### Search behavior
Put the canonical lesson title and key vocabulary in actual title/body text because WordPress Search searches page/post titles and body content; do not rely on tags alone for findability.

# HOSI Public Campus — Page Blueprints

These are public-page content blueprints for the WordPress.com Free campus. Adapt visual layout to the selected accessible theme while preserving meaning, review status, and scope.

## Home

### H1
Human Operating System Institute

### Motto
**Learn the Operating System Before the Diagnosis.**

### Intro
HOSI is an evidence-first educational institute for learning how attention, memory, learning, emotion, sleep, circadian timing, motivation, stress, relationships, behavior and recovery interact before reducing a person to a diagnostic label.

### Primary actions
- Start Here
- Explore HOSI-101
- Learn how HOSI handles evidence

### Principle callout
**Diagnoses are maps, not identities.** A diagnosis may help describe patterns, guide research, support communication and inform care. It is not a complete description of a person's worth, intelligence, behavior or future.

### Campus cards
- HOSI-101
- Colleges
- Study Paths
- Research Library
- Atlas
- Corrections & Updates

### Status note
Clearly state which areas are published curriculum, which are drafts/prototypes, and which remain under review.

## Study Paths

### H1
Study Paths

### Intro
A study path is an educational lens. It is not a diagnostic result and does not imply that every learner following the path has that condition.

Each path includes:
- ordinary system prerequisites
- condition/framework foundations
- related skills/therapies
- research-literacy lessons
- combination/intersection notes where evidence exists

### Combination paths
If a combination path has sparse or indirect evidence, say so visibly.

Never make every combination look equally evidence-dense just because the navigation grid has equal-sized cards.

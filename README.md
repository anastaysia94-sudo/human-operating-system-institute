# Human Operating System Institute (HOSI)

> **Learn the Operating System Before the Diagnosis.**

HOSI is an open educational project focused on the human mind, brain, behavior, cognition, recovery, evidence literacy, and practical skill development. The flagship study paths cover Bipolar I, Bipolar II, ADHD presentations, OCD, PTSD/trauma, brain injury/TBI, and meaningful combinations of these areas.

## Core principles

- Diagnoses are maps, not identities.
- Person-first, systems-first, evidence-first education.
- Psychological, behavioral, educational, interpersonal, environmental, rehabilitative, and pharmacological approaches are evaluated by evidence rather than ideology.
- Lived experience is valuable and is kept distinct from population-level scientific evidence.
- Uncertainty is documented rather than hidden.
- Learners are taught to evaluate evidence, not merely accept conclusions.

## Current development status

This repository is the canonical public source repository for the HOSI project. It currently contains foundational documents and curriculum-development specifications. Production deployment of a WordPress campus, LMS, Atlas AI, certification engine, and peer-review infrastructure is still future work.

## Educational scope

HOSI is an educational project, not a medical practice. Course materials do not diagnose, prescribe, or instruct learners to start, stop, or change treatment. Until appropriate external accreditation/authorization exists, HOSI certificates are certificates of completion rather than professional licenses or accredited degrees.

# HOSI-101 Lessons 81–90 — Behavior, Habits & Environment

Development curriculum block. Each lesson requires source verification, independent review, accessibility review, and assessment validation before final publication.

- 81 — Behavior as a System: observable behavior, context, antecedents, consequences
- 82 — Habit Loops: cues, routines, reinforcement, automaticity
- 83 — Behavioral Activation: activity, avoidance, reinforcement, values
- 84 — Implementation Intentions: if–then plans, cues, action specificity
- 85 — Environmental Design: friction, defaults, prompts
- 86 — Avoidance and Negative Reinforcement: short-term relief and long-term maintenance
- 87 — Behavioral Experiments: prediction, observation, revision
- 88 — Relapse Prevention: warning signs, coping plans, support
- 89 — Self-Management Without Self-Blame: agency, limits, context
- 90 — Module Review: Behavior

Standard lesson object: objectives → human-system baseline → core teaching → evidence map → condition lenses → combination evidence → practical skill → Cornell Notes → knowledge check → homework → instructor key → references → research update → “What would change our mind?”

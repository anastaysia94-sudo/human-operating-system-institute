# HOSI Founder's Atlas

## Working title
**HOSI-000 — The Human Operating System Atlas: Founder's Cognitive Biography**

This is an autobiographical/oral-history and reflective archive, not a clinical psychological evaluation.

## Purpose
Document the founder's origins, childhood, family, education, cognition, attention, emotion, health journey, adversity, treatment experiences, philosophy, faith, intellectual influences, leadership, birth of HOSI, and legacy.

## Question architecture
Each question should include:
- question ID
- purpose
- reflection guidance
- primary narrative
- Cornell Notes
- timeline/context
- memory confidence
- optional corroboration
- alternative interpretations
- lessons learned
- future reflection
- Human Operating System tags
- relevant study-path tags

## Diagnostic-path representation
The Atlas may reference Bipolar I, Bipolar II, ADHD presentations, OCD, PTSD/trauma, brain injury, and combinations only as contexts for educational reflection. It must not infer or assign a diagnosis.

## Founder testimony
Personal treatment experiences are preserved as lived experience. They must remain distinct from population-level scientific evidence.
